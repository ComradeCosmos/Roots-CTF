# CIVILIZATION — Storyline & Logo Concepts

---

## 01 — The Storyline

Drop these pieces in wherever they're needed — CTFd's homepage/About
section, the opening briefing script, era banners, or challenge category
descriptions. Each is written to stand alone, so pick what fits each
surface rather than needing the full text everywhere.

### CTFd Homepage / About Section
> Every system we secure today has a lineage. Writing gave civilization
> its first record-keeping systems. Trade gave it its first trust
> systems. Industry gave it its first networked infrastructure.
> Computing gave it the systems this event is actually about.
>
> CIVILIZATION is structured in five eras — Roots, Settlement, Empire,
> Industry & Information, and Convergence — each one a stage in how
> knowledge becomes infrastructure, and infrastructure becomes something
> worth breaking into. Start wherever matches your experience. Progress
> at your own pace. The scoreboard tracks how far you get — not where
> you started.

### Opening Briefing (spoken, ~45 seconds)
> Before there were networks, there were roads. Before there were
> logins, there was a seal pressed into wax. Every security problem
> we're about to hand you tonight has an ancestor — a version of the
> same problem that someone solved, or didn't, centuries before a
> computer existed to run it.
>
> Tonight you're not just solving challenges. You're walking the same
> arc civilization did — from the first system worth writing down, to
> the first system too complex for any one person to fully understand.
> Five eras. Pick where you start. The scoreboard opens in two minutes.

### Era Intro Lines (for banners / CTFd category descriptions)
- **I. Roots** — *Where knowledge and culture first became systems worth
  recording.*
- **II. Settlement** — *Where trust had to be built into a system for
  the first time.*
- **III. Empire** — *Where systems had to scale, and scale created new
  weaknesses.*
- **IV. Industry & Information** — *Where mechanization gave way to
  computing, and old flaws took new forms.*
- **V. Convergence** — *Where independent systems merge into one, and a
  single flaw can reach everything.*

### Closing / Awards Ceremony Line
> Civilizations aren't remembered for never having a weakness. They're
> remembered for what they built anyway. Whatever era you made it to
> tonight, you made it further than where you started — that's the
> only metric that actually matters here.

### Challenge Description Template
Use this shape for any individual challenge's CTFd description, so
every one reads consistently:

> *[One sentence of era-appropriate framing, e.g. "A settlement only
> works if people trust the record-keeper."]*
>
> [Plain technical brief of what the challenge actually wants solved —
> no flavor text mixed in here, keep it literal.]
>
> Flag format: `CTF{...}`

## 02 — Logo Concept Suggestions

Four directions, written so a designer (or Canva/Illustrator) can build
from the description directly. All assume the existing identity palette
— crimson (`#B91C1C` / `#E8001A`) on dark navy/black, Space Grotesk for
display type, DM Mono for supporting text — the same system already in
use for the club's branding, so this reads as part of the same family
rather than a one-off event logo.

**1. The Root Circuit**
A single root system rendered in thin crimson lines, branching upward —
but where the roots would naturally end in root hairs, they instead
terminate in small right-angle turns, like traces on a circuit board.
Reads immediately as "organic becoming digital" without needing text to
explain it. Works well as a standalone icon at small sizes (favicon,
badge).

**2. The Five Rings**
Five concentric, slightly irregular rings (not perfect circles — hand-
drawn imperfection, like tree growth rings), each one a thin crimson
line on black, with the innermost ring filled solid. Each ring
represents an era; the filled center is Roots. Scales well as a
progress/achievement marker too — could literally be used on the live
dashboard to show how many eras a team has reached.

**3. The Carved Mark**
A single glyph built from two overlapping elements: a vertical line
representing a monolith/obelisk (the "roots" of recorded history), and
a thin crosshair — the mark already associated with the club's existing
identity — centered on it like a targeting reticle finding the flaw in
an old structure. Ties directly into the existing brand mark rather
than inventing a new one from scratch.

**4. Wordmark-Led**
No icon — just "CIVILIZATION" set in Space Grotesk, bold weight, all
lowercase, with the dot of the "i" in each instance replaced by a small
crimson square (echoing a terminal cursor). Clean, text-forward, easy
to put on banners and certificates without fighting for space. Lowest
production effort of the four — good fallback if design bandwidth is
tight before the event.

**Recommendation:** if the club wants brand continuity with the
existing crosshair mark, go with #3. If the dashboard/scoreboard needs
a shape that can double as a progress indicator across the five eras,
go with #2. If there's limited design time before the event, #4 is the
fastest to execute well.
